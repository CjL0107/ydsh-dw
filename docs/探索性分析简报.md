## 1. 分析口径（先定口径，再看数字）

| 概念 | 定义 | 说明 |
|---|---|---|
| 下单订单数 | 15,000 | 去重后全部订单，含待支付/已取消 |
| 有效订单数（已付款） | 10,809 | `order_status ∈ (已支付, 已完成, 退款中)`，即 `is_paid=1` |
| GMV | 27,342,828.20 元 | 有效订单的 `pay_amount` 合计 |
| AOV（客单价） | 2,529.64 元 | GMV / 有效订单数 |
| 折扣率 | 14.04% | 优惠金额合计 / GMV |
| 品类 GMV | 分摊口径 | 订单实付按明细金额占比分摊到品类（原因见第 4 节） |

**为什么区分"下单"和"有效"**：把 2,116 单待支付、2,075 单已取消也算进 GMV，会让客单价被稀释 28%。电商口径里 GMV 一般指成交额，未付款/已取消不计入——这一点在汇报时先讲清楚，后面所有数字才站得住。

## 5. 数据可信度核查

| 核查项 | 结果 | 影响 |
|---|---|---|
| 明细金额 vs 订单实付 | 明细合计 3.05 亿 vs GMV 2,734 万，**差 11.19 倍** | 品类销售额不能直接用 `SUM(明细金额)`，必须分摊 |
| 已付款订单无明细 | 34 单 | 订单/明细不能 1:1 对齐 |
| 行为日志时间范围 | 仅 2024-10-01 ~ 12-31（92 天） | 不能与全年订单按时间对齐 |
| 大促日效应 | 无（日均反而低 7.6%） | 促销分析无意义 |
| 渠道/支付/时段分布 | 近似均匀 | 无结构性洞察 |
| 门店面积 vs 单店 GMV | 无相关性 | 坪效指标不可信 |

**为什么要把这 6 条写进简报**：分析报告的价值不只在于"发现了什么"，也在于"哪些结论不能下"。如果只报喜不报忧，第 3 周做预测模型和看板时会基于错误假设返工。这 6 条同时是答辩时"你对数据理解到什么程度"的最好答案。

## 6. 结论与行动建议

### 6.1 可确认的结论（数据支持）

1. **订单转化是最大杠杆**：28% 订单未成交（待支付 14.11% + 已取消 13.83%），高于行业常见水平（10%~15%）。若把转化率提到 85%，GMV 可提升约 9%。
2. **GMV 结构稳定**：月度 GMV 在 213~240 万之间波动（波动幅度 ±11%），无趋势性增长或下滑，说明业务处于"平稳运营"状态。
3. **用户价值集中在 2~5 万区间**：749 人（74.9%）贡献 82.92% GMV，是运营的核心盘子；≥5 万的 22 人虽是头部，但总量只占 4.27%，不值得投入专属资源。
4. **区域与品类均无强集中**：不存在"单点依赖"风险，但也意味着没有明显的增长突破口。

### 6.2 不可确认的结论（数据不支持，禁止写进汇报）

- 不能说"运动户外是核心品类"——品类分布均匀（14.91% vs 11.03%），差异在噪声范围内。
- 不能说"门店渠道最重要"——四个渠道 GMV 差距 < 1.3%。
- 不能说"大促带来增长"——大促日日均 GMV 反而更低。
- 不能说"旗舰店坪效更高"——单店 GMV 与面积无关。
