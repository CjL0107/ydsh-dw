UNION ALL SELECT 'ods_store', COUNT(*) FROM ydsh_ods.ods_store

## 子任务 5：数据质量预评估

清单要求：五维度（完整性/唯一性/有效性/一致性/准确性）量化扫描，产出 `.xlsx`。

**脚本在哪**：`sql\quality\quality_assess.sql`（扫描）、`docs\数据质量预评估表.xlsx`（8 个工作表的成品）。

**你要亲手敲的命令——每个维度挑一条代表性查询：**

```powershell
# 完整性：空值统计
docker exec hive-server beeline -u jdbc:hive2://localhost:10000 --silent=true -e "
SELECT COUNT(*) AS age_null FROM ydsh_ods.ods_user WHERE age IS NULL OR age = '';"

# 唯一性：重复主键分组
docker exec hive-server beeline -u jdbc:hive2://localhost:10000 --silent=true -e "
SELECT order_id, COUNT(*) AS c FROM ydsh_ods.ods_order GROUP BY order_id HAVING COUNT(*) > 1 LIMIT 10;"

# 准确性：金额负值
docker exec hive-server beeline -u jdbc:hive2://localhost:10000 --silent=true -e "
SELECT COUNT(*) AS neg_pay FROM ydsh_ods.ods_order WHERE pay_amount < 0;"
```

**五维度核心结论（答辩口径，务必记住）：**

| 维度 | 发现 |
|---|---|
| 完整性 | 邮箱缺 19.3%、年龄缺 51 条、上架日期缺 11 条 |
| 唯一性 | **订单表 586 组重复、多出 600 行**（最严重） |
| 有效性 | 性别 7 种写法、订单状态 12 种写法、8090 条日期格式不统一 |
| 一致性 | 主外键孤儿记录 0，省市口径一致 |
| 准确性 | pay_amount 负值 310 条、最大值 995 万（异常） |

**验收标准**：五维度均有量化结果 ✅（xlsx 已生成，8 个工作表）

## 子任务 6：清洗（一）—— 缺失值处理

清单要求：定位缺失字段，制定填充策略，输出 DWD 目标表。

**脚本在哪**：`sql\clean\clean_user.sql`、`sql\clean\clean_product.sql`。

**填充策略（答辩必背）：**

| 字段 | 缺失量 | 策略 | 理由 |
|---|---|---|---|
| age | 51 + 27 条异常 | 用**有效区间均值 41.2 岁**填充 | 分布稳定，均值填充无偏 |

## 子任务 7：清洗（一）—— 重复值检测与去重

清单要求：区分整行重复与主键重复，用窗口函数去重，统计前后行数差异。

**脚本在哪**：`sql\clean\clean_order.sql`。

**核心逻辑（要能默讲）：**

```sql
INSERT OVERWRITE TABLE dwd_order
SELECT * FROM (
  SELECT *, ROW_NUMBER() OVER(
    PARTITION BY order_id ORDER BY order_date, order_time
  ) rn FROM ods_order
) t WHERE rn = 1;
```

原理：按 `order_id` 分组，组内按时间排序编号，只留 `rn = 1` 那条。

**586 组重复的两类形态（这是本题最深的考点）：**

| 类型 | 组数 | 成因 | 处理 |
|---|---|---|---|
| A：整行完全重复 | 388 | 调度重跑/重复导入 | 留任意 1 条，无信息损失 |
| B：主键同但内容不同 | 198 | 业务侧重复提交 | 按规则选最可信的一条 |

**验证命令：**

```powershell
docker exec hive-server beeline -u jdbc:hive2://localhost:10000 --silent=true -e "
SELECT COUNT(*) AS dwd_order_rows FROM ydsh_dwd.dwd_order;"
```

**预期结果：15000**（15600 − 600 = 15000，删除 600 行，这个减法要能脱口而出）
